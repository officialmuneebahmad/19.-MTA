# Brand Logos Needed — Multan Tech Accessories

This document lists all active brands in the MTA catalog sorted by active product count, along with the expected logo file names for single and bulk ZIP uploads.

> **Important Note for Store Owner:**
> Always use official, high-resolution logo files directly from brand press kits, distributor assets, or vector repositories (SVG preferred, or transparent PNG/WebP with at least 400px width). Never scrape or hotlink low-quality third-party thumbnails.

## Bulk Upload Instructions
1. Create a `.zip` file containing vector SVGs or transparent PNGs matching the **Expected File Name** column below (e.g., `faster.svg`, `baseus.png`).
2. Navigate to **Admin Console &rarr; Brand Logos & Featured &rarr; Bulk Logo Import (ZIP Archive)**.
3. Upload the archive. The system automatically sanitizes SVGs, optimizes rasters to crisp WebP at 2x resolution, and assigns each logo to its respective brand.
